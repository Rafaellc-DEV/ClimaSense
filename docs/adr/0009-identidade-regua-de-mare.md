# ADR 0009 — Identidade visual “régua de maré”

- **Situação:** aceita
- **Data:** 15/10/2026

## Contexto

O produto precisa de uma identidade própria, moderna e não genérica, legível para pessoas idosas.

## Decisão

A régua linimétrica das pontes do Capibaribe vira a linguagem de nível. Atkinson Hyperlegible Next como fonte única, cores da logo, cartografia em traço a partir dos dados oficiais.

## Consequências

Um elemento memorável com função. Contraste verificado por teste. Guia em `docs/brand/guia-de-marca.md`.
