Downloads

Escolha abaixo o arquivo para realizar o download:
  1. Base de Dados Completa: Excel (XSLX) / Ponto e Vírgula (CSV) - Apenas Valores Corrigidos

    Este arquivo contém toda a base de dados do Atlas, em formato Excel. No arquivo, são disponibilizadas três tabelas. A primeira, denominada Atlas – Valores Originais, possui os valores monetários conforme registrado pelo ente federado à época da ocorrência. A segunda, denominada Atlas – Valores Corrigidos, contém os mesmos registros, porém com os valores atualizados para dezembro de 2022. Por fim, a terceira tabela, denominada Cálculo Correção, contém os valores do índice utilizado para correção dos valores monetários (IGP-DI) e os fatores de conversão relativos a este índice. O arquivo em formato CSV possui apenas a tabela com os valores já corrigidos.

  2. Manual de Tratamento da Base de Dados: PDF.

    Este manual explica a origem dos dados, a metodologia de tratamento utilizada e o processo de atualização de valores monetários.

  3. Log de Correções da Base de Dados: Logs.

    Este arquivo tem por objetivo registrar e prestar contas das alterações e correções realizadas na base de dados. Como os registros são realizados manualmente e os municípios que preenchem os dados normalmente se encontram sob pressão dos desastres que ocorrem em seu município, equívocos de preenchimento podem acontecer. Quando detectados, estes equívocos são corrigidos e registrados neste arquivo, para que os usuários desta base de dados tenham conhecimento das alterações realizadas.
